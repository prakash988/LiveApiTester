# LiveApiTester - AI-Powered Live API Testing Plugin for IntelliJ IDEA

Test APIs live inside IntelliJ IDEA with AI-powered debugging, test generation, and smart suggestions. Like Postman, but smarter and built into your IDE.

## Status
🚧 Under Development

## Features (Planned)
- Live HTTP Client (GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS)
- AI-Powered Error Analysis & Fix Suggestions
- AI Test Case Generation
- Endpoint Scanner (Spring Boot & JAX-RS)
- Collections & Environments Management
- Request History
- Variable Interpolation
- Auth Support (Bearer, Basic, API Key, OAuth)
- cURL Import/Export

## Tech Stack
- Kotlin + Gradle
- IntelliJ Platform Plugin SDK
- OkHttp 4.x
- OpenAI-compatible API
